## 2. 工作台（仪表盘）

> 路径：点击侧边栏「工作台」或首页

工作台是系统总览页面，分为以下几个区域：

### 2.1 顶部统计卡片
- **线路** — 运营商线路总数
- **项目** — 空间节点总数
- **活跃合同** — 进行中+即将到期的合同数
- **紧急警报** — 红色告警数量（有告警时变红）

### 2.2 线路已过期 / 即将到期（红区）
- 显示已过期 + **15天内**到期的运营商线路
- 每条显示：到期天数标签 + 电路编号 + 运营商 + 年费 + 影响项目/客户数
- **红色标签**：已过期或7天内到期 → 需紧急处理

### 2.3 终端客户合同临期（黄区）
- 显示**30天内**到期的客户合同
- 表格形式：合同编号 / 客户名称 / 业务类型 / 计费 / 到期日 / 状态 / 续约按钮
- 可直接点击「续约」跳转到续约操作

### 2.4 级联影响：运营商线路到期对下游影响
- 显示**60天内**到期的运营商线路
- 突出显示"此线路中断将影响 X 个项目及 Y 个客户"

### 2.5 超卖风险看板
- 检测带宽分配超出总带宽的项目
- 显示超卖比例，>150% 标记为红色拥堵风险

## 3. 资源管理（运营商线路）

> 路径：侧边栏「资源管理」

管理从运营商租用的物理/逻辑线路。

### 3.1 线路列表
- 显示：线路编号 / 运营商 / 电路编号 / 总带宽 / 采购日期 / 到期日 / 剩余天数 / 年成本 / 安装位置 / 备注 / 照片
- 支持搜索（按线路编号/运营商/电路编号）
- 全选复选框在表格左上角表头

### 3.2 新增/编辑线路
- **必填项**：线路编号、运营商、电路编号、总带宽、采购日期、到期日期
- 线路编号根据运营商自动生成前缀（电信→CT-、联通→CU-、移动→CM-）
- **设备照片**：支持多张图片上传，点击图片预览
- **安装位置**：机房/机柜具体位置
- **备注**：其他信息

### 3.3 批量操作
- 勾选多条线路 → 底部出现批量删除栏
- 点击「取消选择」或全选复选框取消勾选

## 4. 项目管理（空间节点）

> 路径：侧边栏「项目管理」

管理园区、楼宇、散点等空间节点，并关联运营商线路。

### 4.1 节点列表
- 显示：节点编号 / 项目名称 / 类型 / 承载线路 / 电路编号 / 线路到期日
- 支持搜索

### 4.2 新增/编辑节点
- **必填项**：节点编号、项目名称、项目类型
- **承载线路**：可多选运营商线路（复选框列表）
- 一个节点可以关联多条线路

### 4.3 线路关联作用
- 用于计算**级联影响**（线路到期会影响到哪些项目/客户）
- 用于**超卖检测**（项目已分配带宽之和 vs 关联线路总带宽）

## 5. 客户管理

> 路径：侧边栏「客户管理」

### 5.1 客户列表
- 显示：编号 / 公司名称 / 类型 / 安装地址 / 联系人 / 联系电话 / 微信状态
- 连锁店客户会显示所属总部
- 支持搜索
- 右上角「连锁树」查看连锁结构

### 5.2 新增/编辑客户
- **必填项**：客户编号、公司名称、客户类型
- 客户类型在系统设置中自定义
- **微信 OpenID**：可手动填写或点击「扫码绑定」通过公众号二维码获取

### 5.3 客户全景
- 点击客户行「全景」按钮
- 展示：客户基本信息 + 合同统计（进行中/即将到期/已过期）+ 关联合同列表 + 旗下分店
- 合同卡片显示：编号 / 状态 / 业务类型 / 安装位置 / 周期 / 费用

### 5.4 连锁店结构
- 总部客户（类型=连锁店，无上级）下设分店
- 分店关联总部，在连锁树中展示层级关系

## 6. 合同管理

> 路径：侧边栏「合同管理」

### 6.1 合同列表
- 顶部统计卡：进行中 / 即将到期 / 已到期 / 已续约
- 表格：合同编号 / 客户名称 / 业务类型 / 安装位置 / 带宽 / 生效日 / 到期日 / 剩余天数 / 状态 / 计费
- 支持搜索
- 全选复选框在表格左上角表头

### 6.2 新增/编辑合同
- **必填项**：合同编号、关联客户、业务线、生效日期、签约周期
- **到期日自动计算**：生效日 + 签约周期，不可人工修改
- 业务类型可选：宽带自运营 / 宽带直售 / IT外包
- 计费周期：月费 / 季费 / 年费（费用字段提示联动）

### 6.3 续约功能
- 对**即将到期**或**已到期**的合同，点击「续约」按钮
- 系统自动克隆原合同数据，生成新合同编号
- 可修改：新开始日（默认顺延）、签约周期、计费周期
- 续约后在原合同下**折叠显示**，可展开/收起查看

### 6.4 撤销续约
- 对已续约的原合同，点击「撤销续约」
- 删除续约产生的新合同，恢复原合同状态

### 6.5 合同状态自动管理
- 系统自动根据 `end_date` 更新状态
- 每天09:00 + 每次操作后实时刷新

## 7. 系统设置

> 路径：侧边栏「系统设置」（需管理员/经理角色）

### 7.1 组织架构
- **部门管理**：添加/编辑/删除部门，树形层级结构
- **人员管理**：添加/编辑/删除人员（含微信 OpenID 字段）
- **角色权限**：
  - 可自定义角色名称
  - 权限矩阵：角色 × 页面（点击切换 ✔/—）
  - 支持增删角色

### 7.2 常规配置

| 配置项 | 说明 |
|--------|------|
| 系统名称 | 浏览器标题 |
| 系统缩写 | 侧边栏顶部显示 |
| 公司名称 | 品牌信息 |
| Logo 副标题 | 侧边栏说明文字 |
| Logo 图片 | 上传自定义Logo |
| 提醒提前天数 | 合同到期状态切换阈值 |
| 管理通知时间段 | JSON数组，如[60,30,15,7,3,1]，自定义提醒触发时间 |
| 自动续约提醒 | 开关 |
| 定时任务 Cron | 提醒引擎运行时间 |

### 7.3 微信配置

| 配置项 | 说明 |
|--------|------|
| 公众号 AppID / AppSecret | 微信开发凭据 |
| 服务器 Token | 用于回调验证 |
| OAuth 回调地址 | 网页授权回调 |
| 到期提醒模板ID | 发给终端客户 |
| 续约成功模板ID | 发给终端客户 |
| 管理通知模板ID | 发给内部管理人员 |
| 企微机器人 Webhook | 站内通知 |
| 管理通知接收人 | 从员工列表勾选（需先填写员工微信OpenID） |

### 7.4 业务配置
- **客户分类**：自定义客户类型（增删改）
- **合同业务类型**：自定义业务类型

## 8. 数据导入导出

### 8.1 导出 Excel
- 每个管理页面（资源/项目/客户/合同）均有「导出」按钮
- 生成带样式的 `.xlsx` 文件（蓝底白字表头 + 斑马纹）

### 8.2 下载模板
- 点击「模板」按钮下载导入模板
- 模板为 `.xlsx` 格式，含中文表头

### 8.3 导入数据
- 点击「导入」按钮，选择填好的 `.xlsx` 文件
- 系统自动识别中文表头，映射到正确字段
- 也支持 `.csv` 格式（中英文表头均可）
- 导入结果提示成功条数和错误详情

## 9. 微信集成

### 9.1 前置条件
1. 拥有已认证的微信公众号（服务号）
2. 在微信公众平台开通模板消息功能
3. 配置 IP 白名单为服务器 IP

### 9.2 配置步骤
1. **系统设置 → 微信配置**：填写 AppID、AppSecret
2. **微信公众号平台** → 添加服务器配置（URL、Token）
3. **创建模板消息**：分别创建到期提醒、续约成功、管理通知模板
4. 将模板ID填入系统设置

### 9.3 客户扫码绑定
- 在客户管理 → 全景视图 → 点击「扫码绑定」
- 系统生成临时二维码，客户扫码关注公众号后自动绑定 OpenID
- 绑定后客户可收到微信续约/到期通知

### 9.4 管理通知
- 在员工管理中填写微信 OpenID
- 在微信配置中勾选需接收通知的员工
- 配置管理通知模板ID
- 系统按自定义时间段合并发送到期汇总提醒

## 10. 提醒引擎

### 10.1 触发方式
- **自动**：每日 09:00（可自定义 Cron）
- **手动**：点击顶部栏「运行提醒」按钮

### 10.2 提醒内容

| 类型 | 接收对象 | 内容 |
|------|---------|------|
| 线路临期预警 | 企业微信机器人 | 影响的项目和客户数 |
| 客户合同到期 | 终端客户（微信） | 服务即将到期提醒 |
| 客户合同到期 | 企业微信机器人 | 客户详情和联系人 |
| 管理通知汇总 | 勾选的管理人员（微信） | 按时间段归并的到期清单 |

### 10.3 自定义时间段
- `reminder_advance_days` 配置触发天数
- 默认 `[60, 30, 15, 7, 3, 1]`：到期前60天/30天/15天/7天/3天/1天
- 可在常规配置中修改为任意天数数组

## 11. 常见问题

### Q: 页面加载不出来？
- 检查服务器是否运行：`http://localhost:3100`
- 浏览器缓存：Ctrl+F5 强制刷新
- 查看版本号：`index.html` 中静态资源 `?v=` 参数确保最新

### Q: 导入数据全部失败？
- 使用系统生成的模板（点击「模板」下载）
- 确保表头与模板一致（中英文均可）
- 支持 `.xlsx` 和 `.csv` 格式

### Q: 微信通知发送失败？
- 检查 AppID/AppSecret 是否正确
- 检查模板ID是否在公众号后台创建
- 检查服务器 IP 是否在微信白名单
- 检查接收人是否已关注公众号
- 查看服务器控制台错误日志

### Q: 合同状态不正确？
- 系统自动更新，也可点击顶部「运行提醒」
- 创建/编辑/续约/导入后会自动刷新

### Q: 如何隐藏侧边栏？
- 点击顶部栏左上角 **☰ 按钮**

### Q: 如何添加新员工？
- 系统设置 → 组织架构 → 人员管理 → 新增人员
- 填写编号、姓名、账号、角色等信息
- 如需微信通知，填写微信 OpenID

### Q: 如何批量删除？
- 勾选目标项（左上角表头全选）
- 底部出现批量删除栏 → 点击「批量删除」
